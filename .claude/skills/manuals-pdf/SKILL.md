# manuals-pdf

สร้าง `manual.pdf` ที่รากโปรเจกต์ จากภาพ `manuals/<section>-<NN>-<step>.png` ด้วย `e2e-test/build-manual.ts` (Playwright เรนเดอร์ HTML เป็น PDF ใช้ฟอนต์ไทยของระบบ)

## ขั้นตอน
1. **ตรวจภาพ** `ls manuals` ต้องเป็นรูปแบบ `<section>-<NN>-<step>.png` (เช่น `order-03-add-to-cart-1.png`) ถ้ายังไม่มีภาพหรือภาพเก่า ให้รัน e2e script ก่อน (ดู skill `add-e2e-test`): ต้องเปิด frontend `:4200` และ backend `:3000` อยู่ แล้ว `cd e2e-test && npx tsx order.ts` / `npx tsx review.ts`
2. **เปิดดูภาพ** 2-3 ภาพ เพื่อยืนยันว่ามีกรอบแดงและวงกลมเลขลำดับ และเลขตรงกับ NN ในชื่อไฟล์
3. **ตรวจคำอธิบาย** ใน `SECTIONS` ของ `e2e-test/build-manual.ts`
   - แต่ละ section มี `prefix` (ตรงกับต้นชื่อไฟล์), `title`, `intro`, และ `steps` โดย key คือชื่อ step ในชื่อไฟล์ (ไม่รวมเลข NN) เช่น `add-to-cart-1` ใช้คำอธิบายของ `add-to-cart` (ตัดท้าย `-<เลข>` อัตโนมัติ)
   - ถ้ามีภาพ step ใหม่ที่ไม่มีคำอธิบาย สคริปต์จะ error `ไม่มีคำอธิบายสำหรับ <ไฟล์>` ให้เพิ่มคำอธิบายภาษาไทยที่บอกว่า "กดอะไร / กรอกอะไร / ผลที่เห็น" ตามที่เห็นในภาพจริง
   - ถ้าเพิ่มฟีเจอร์ใหม่ (section ใหม่) ให้เพิ่ม object ใหม่ใน `SECTIONS`
   - คำอธิบายต้องไม่อ้างค่าที่สุ่ม (ชื่อ ที่อยู่ สินค้า) เพราะแต่ละรอบไม่เหมือนกัน
4. **สร้าง PDF** `cd e2e-test && npx tsx build-manual.ts` → ได้ `manual.pdf` ที่รากโปรเจกต์ (ไฟล์ `manual.html` ชั่วคราวถูกลบเอง)
5. **เปิดดูผล** บน Windows: `Start-Process <path>\manual.pdf` ตรวจว่าภาษาไทยไม่เป็นสี่เหลี่ยม ภาพไม่ถูกตัดขอบ และเลขลำดับในหัวข้อตรงกับเลขในภาพ (ถ้าเครื่องมี poppler ใช้ Read ดูเป็นหน้าได้ ถ้าไม่มีจะอ่านภาพหน้า PDF ไม่ได้ ให้บอกผู้ใช้ว่ายังไม่ได้ตรวจด้วยตาตัวเอง)
6. **สรุปให้ผู้ใช้**: จำนวนหน้า, section ที่มี, step ที่ไม่ปรากฏเพราะการสุ่ม (เช่น กรอกบัตรปรากฏเฉพาะรอบที่สุ่มได้บัตรเครดิต)

## เค้าโครงเอกสาร
- หน้าปก: ชื่อคู่มือ + คำอธิบายวิธีอ่านเลขลำดับและกรอบแดง
- แต่ละ section ขึ้นหน้าใหม่ มีหัวข้อและคำอธิบายนำ
- แต่ละ step: วงกลมแดงเลขลำดับ + หัวข้อ + คำอธิบาย + ภาพเต็มความกว้าง (ไม่ตัดข้ามหน้า)

## ข้อควรระวัง
- ภาพใน `manuals/` ที่ชื่อไม่ขึ้นต้นด้วย prefix ของ section ใดจะถูกข้าม
- ภาพเก่าที่เหลือจากรอบก่อน (เช่น กรอกบัตรเมื่อรอบนี้ไม่ได้สุ่มบัตร) จะอยู่ในคู่มือด้วย ถ้าเลขลำดับไม่ต่อเนื่อง ให้รัน e2e script ใหม่เพื่อล้างภาพของ prefix นั้น
- ใช้ Write สร้างไฟล์สคริปต์ยาว ๆ ที่มีภาษาไทย/เครื่องหมายพิเศษ แทน heredoc ใน bash
